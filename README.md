# Grace Technologies Ltd. Website

Next.js App Router corporate website built with TypeScript, React, CSS Modules, global CSS tokens, and Lucide React.

## Development

Run from this project directory, which contains `package.json`:

```powershell
npm install
npm run dev
```

Open http://localhost:3000. For a production build, run `npm run build`; to serve it locally, use `npm run start` after the build completes.

## Site URL and SEO

Set `NEXT_PUBLIC_SITE_URL` to the deployed canonical origin (for example, `https://www.example.com`) in the deployment environment. This value is used for canonical metadata and the generated sitemap. Until the actual domain is configured, the sitemap intentionally contains no URLs rather than publishing an invented domain.

The sitemap and robots files are generated by `src/app/sitemap.ts` and `src/app/robots.ts`.

## Enquiry form

The enquiry form currently performs browser-side validation only. It does not send or store submissions. Before launch, connect it to the selected backend (such as Supabase), add appropriate server-side validation and abuse protection, and replace the demonstration privacy and terms copy with reviewed policies.

## Structure

- `src/app/` contains public routes and route metadata.
- `src/components/` contains shared layout, enquiry, and homepage section components.
- `src/lib/site-data.ts` contains service, industry, project, and sample content.
- `src/app/globals.css` defines the three base colors and shared design tokens.
- `public/` contains static assets.

No official Grace Technologies logo or business imagery was present in `public/` when this site was updated. The header and footer therefore use a text-only wordmark, and the hero uses an original CSS dashboard illustration. Add approved brand assets to `public/assets/` when they are available.
